## 2. What the collection is

The mirror is a save of a Vue 2 / Vant mobile web application (`www.ah33c5.org/m`) plus
its member-centre bundle (`/mobile/mc`), a lottery bundle (`/lotto`), five third-party
CDN libraries, an image CDN directory (`images.84815068.com`), and one captured DOM
snapshot (`website-source-export/index.html`, 1.4 MB) with bundled styles inlined.

* **Not a source tree.** There is no `package.json`, no component `.vue` files, no source
  maps, and no build configuration. The JavaScript is webpack-bundled and minified.
* **Not a complete site.** Only the mobile entry (`/m`) and the member-centre shell were
  captured. The game clients themselves (the provider iframes) are remote and absent, as
  are all API responses, the real banners behind the 18 carousel slides, and the
  provider-level game catalogue beyond the 57 cached thumbnails.
* **Snapshot, not live HTML.** `index.html` contains the rendered lobby (18 banner slides,
  49 game cards, the winners ticker) with the webpack runtime inline. Refetching the live
  `/m/index.html` returns a 7.5 KB shell and the app builds the rest client-side.

## 6. Inventory caveats

* Dimensions were read with `getimagesize()` (GD/Imagick available in the build VM), which
  understands AVIF, WebP, PNG, JPEG and GIF.
* MIME types come from `finfo`, with the image type from `getimagesize()` taking precedence.
* MD5 is recorded to prove there are no byte-identical duplicates in the collection. The two
  `website-source-export` trees were compared separately with `diff -rq` (no differences).
* Fonts: **none**. The reference uses the platform system font stack, so no font files were
  captured and none are needed.
* SVG: **none** as standalone files; the site inlines its icon sprites into JavaScript.
