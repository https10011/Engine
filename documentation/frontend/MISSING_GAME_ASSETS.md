# Missing Game Assets and Placeholders

AURUM ships no third-party artwork. Everything missing is listed here, with the exact
path to drop a replacement into and the effect of doing so.

## 1. Policy recap

The 57 provider thumbnails and 13 provider wordmarks in `AH77_SOURCE/` cannot be
redistributed. Each registered game therefore uses a generated SVG tile that shows the
game's own name, provider and theme. It is a deliberate placeholder, not a claim of
provider art: tiles include the text `ENGINE APPROXIMATION`.

### Replacing a tile

1. Obtain artwork you have the right to use.
2. Save it at the same path, or update the path in `views/lobby.js` (`tile()`), the slot
   header and the table headers.
3. Keep a square aspect ratio. The CSS crops with `aspect-ratio: 1 / 1` and
   `object-fit: cover`; a 400×400 or 600×600 SVG/PNG/WebP is ideal.
4. Do not remove the licence/credit requirements of the new asset.

Regenerating all tiles from current metadata:

```bash
curl -s http://127.0.0.1:3000/api/v1/games/lobby > /tmp/lobby.json
php tools/generate_assets.php /tmp/lobby.json public/assets
```

## 4. What "placeholder" means in the UI

* **Tiles** are labelled `ENGINE APPROXIMATION` below the emblem, so a player is not
  shown provider branding that would imply an official port.
* **Synthetic modules** keep their engine names and `Engine Test Fixtures` provider line.
  They are playable, but are labelled as fixtures.
* **Coin Flip** is labelled `Engine Examples` and states its fixed heads call and 50%
  reported RTP. It is not disguised as a commercial title.
* No tile, banner or game screen promises a prize, deposit, bonus or real-money payout.

## 5. Adding licensed art later

If the project obtains licences for the original provider artwork:

1. Replace the tile files at the paths above, or change the catalogue's art mapping.
2. Keep the attribution required by the licence in the footer or an about page.
3. Update `ASSET_MAPPING.md` and this file so the provenance record stays accurate.
4. Do not reintroduce the reference site's deposit/bonus banners: they describe products
   this engine does not have.
